# XML Including Reader
XML inlucding reader originally open-sourced on GotDotNet.  It has been updated to run on newer .Net frameworks and packaged.

## Requirements

Version 1.2.0 and later require .NET 10. Build with the .NET 10 SDK and its default C# 14 language version.

Version 1.1.2 is the final .NET 8 release and is no longer maintained.
